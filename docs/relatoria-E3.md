# Relatoría E3

1. **Propósito.** Medir una mejora del procesamiento y preparar un conjunto curado con procedencia y condiciones de reutilización para terceros.
2. **Trabajo realizado.** El 25/11/2026 se actualizó el repositorio local a `ceceab9`; se evitó reinterpretar fechas de captura repetidas en la normalización y se documentó el agregado DENUE. La asistencia de Codex se usó para código, mediciones y documentación; no se atribuyen horas ni revisiones personales no registradas.
3. **Resultados.** En 1,483 filas Banxico, la mediana bajó de 1.654 a 0.506 segundos; el pico de memoria Python bajó de 2,100,184 a 2,085,726 bytes. Los rechazos reales permanecieron en cero y los tres defectos inyectados se detectaron en ambos casos. La comparación cubre una etapa, no todo el pipeline. El agregado contiene 28 celdas y 608 establecimientos; 24 quedaron suprimidos.
4. **Problemas y decisiones.** No se documentó una licencia abierta inequívoca de ASIPONA, por lo que se seleccionó DENUE con sus propias condiciones. Las etiquetas locales antiguas e1/e2 difieren del remoto; no se sobrescribieron. La memoria medida excluye asignaciones nativas y no equivale a RSS. No existe evidencia de que esta mejora provenga de un experimento o auditoría externa.
5. **Pendientes y aprendizaje.** Falta contrastar recomendaciones o combinación ganadora reales, medir obtención y errores en operación, y completar los componentes estadísticos y de calidad del paquete integrador. El formulario oficial no se proporcionó. Las cifras no prueban una reducción de errores ni un sello obtenido.
